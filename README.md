# 📘 FSAE Dynamometer Project

This repository contains the documentation, CAD models, simulation results, and final interactive report for the NUS FSAE Electric Vehicle (EV) hub-mounted dynamometer project.

The goal of this project is to design a compact, portable, and safe dynamometer capable of measuring torque and power directly from the EV's wheel hub under controlled conditions.

---

## 🚗 Project Overview

Commercial chassis dynamometers are typically unsuitable for Formula Student EV applications due to size, cost, and safety limitations.  
This project develops a custom hub-mounted dynamometer tailored to the NUS FSAE EV, focusing on:

- Structural frame design  
- Wheel hub mounting and flange interface  
- Cooling system design  
- Motor selection and evaluation  
- Finite Element Analysis (FEA)  
- Design iteration and validation  
- Interactive documentation and visualisation  

The current phase (Semester 1) focuses on mechanical design.  
Testing will be carried out in Semester 2.
