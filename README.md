# 📘 FSAE Dynamometer Project

This repository contains the documentation, CAD models, simulation results, test data, and final interactive report for the NUS FSAE Electric Vehicle (EV) hub-mounted dynamometer project.

The goal of this project is to design a compact, portable, and safe dynamometer capable of measuring torque and power directly from the EV's wheel hub under controlled conditions, while remaining practical for workshop use and structural validation.

---

## 🚗 Project Overview

Commercial chassis dynamometers are typically unsuitable for Formula Student EV applications due to size, cost, packaging, and safety limitations.  
This project develops a custom hub-mounted dynamometer tailored to the NUS FSAE EV, with work spanning:

- Structural frame design  
- Wheel hub mounting and flange interface  
- Cooling system integration  
- Additional design elements for workshop usability  
- Experimental testing and validation  
- Simulation studies, including modal and fatigue analysis  
- Final fabrication, assembly, and deployment  
- Interactive documentation and visualisation  

The final report presented in this repository covers the full design cycle from concept development to physical testing, simulation verification, and final prototype completion.
